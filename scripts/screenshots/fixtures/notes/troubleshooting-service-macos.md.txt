# Troubleshooting: service install on macOS

## The service does not start

1. Run `emend service status`. It prints the launch agent's state and its last exit code.
2. Check that the port is free: another program may hold it.
3. Run `emend service uninstall`, then `emend service install` again.

## The browser shows a blank page

The server is up but the browser holds an old build. Reload the page with the cache bypassed.

## Still stuck

Open an issue and include the output of `emend service status`. Leave out anything you do not want to share.
